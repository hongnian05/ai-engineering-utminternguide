# Data Directory Structure & V2 Pipeline Storage — UTM-InternGuide

This directory stores raw source documents, cleaned page-level text dumps, validated JSONL chunks, cryptographic lineage manifests, and the persistent local vector index for **UTM-InternGuide**.

---

## Directory Organization

```text
data/
├── README.md                          # Data directory & transformation documentation
├── source_registry.json               # Structured metadata & SHA-256 registry (17 sources: 15 indexed, 2 excluded)
├── collection_log.json                # Automated download & HTTP verification log
├── pipeline_manifest.json             # V2 multi-source SHA-256 lineage & vector index manifest
├── week3_manifest.json                # Preserved Week 3 baseline manifest
├── raw/                               # Original immutable source documents organized by faculty
│   ├── ugs/                           # UTM School of Undergraduate Studies (2024 Senate Guideline, 2025 Int. ToR)

│   ├── fkm/                           # Faculty of Mechanical Engineering (Web + Dec 2023 ITS English Manual)
```

## V2 Data Transformation Stages (`src/pipeline.py`)

| Stage | Module | Behavior |
| :--- | :--- | :--- |
| **1. Source Ingestion** | `src/ingestion.py` | Loads approved sources (`include_in_index=True`) from `data/source_registry.json`, verifies SHA-256 hashes, skips duplicates and excluded Class F sources. |
| **2. Page Extraction** | `src/extraction.py` | Extracts text page-by-page using PyMuPDF (`pymupdf`), extracts structured Markdown tables with `pdfplumber`, and applies OCR only on scanned/image-only pages (`< 25` chars). |
| **3. Text Cleaning** | `src/cleaning.py` | Strips isolated page numbers, normalizes PDF bullet glyphs, repairs hyphenated line breaks, and preserves both English (`en`) and Bahasa Melayu (`ms`) text. |
| **4. Section-Aware Chunking** | `src/chunking.py` | Splits by detected section headings (`SECTION`, `SEKSYEN`, `BAHAGIAN`, numbered headings), respects sentence/table boundaries, never splits words, retains 1-indexed `page_number`, and merges tiny fragments. |
| **5. Automated Validation** | `src/validation.py` | Runs 13 automated quality checks and writes real execution evidence to `docs/data_quality_report.md`. |
| **6. Vector Indexing** | `src/embeddings.py`, `src/vector_store.py` | Builds bilingual word + subword TF-IDF vectors with full chunk metadata and persists the index to `data/vector_store/`. |
